# Renovax Drug Sell v2

Sell drugs to any NPC in the world. No fixed locations. No boring menus. Just walk up, negotiate, and deal — or get refused.

## — FEATURES LIST —

### Core Features:
- **Sell to any NPC** — Every pedestrian is a potential buyer. Blacklist filters out police, EMS and army automatically.
- **One-shot interaction** — Each NPC can only be approached once. No farming the same ped.
- **NPC Refusal** — Random chance for NPCs to refuse before the UI opens, with unique quotes per buyer type.
- **Inverted price logic** — Lower price = higher chance. Real-time feedback on the slider.

### Customization and Compatibility:
- **ESX & QBCore** — Full support for both frameworks out of the box.
- **ox_inventory, qb-inventory, codem-inventory** — Auto-detected at runtime.
- **ox_target, qb-target, TextUI, DrawText** — Swap interaction method with one config line.
- **Full localization** — Ships with `cs` and `en`. Easily extendable.

### Additional Features:
- **XP & Level Progression** — Earn XP per sale, unlock passive chance bonuses at higher levels.
- **NPC Animations** — Stop, face, exchange, walk away. Full immersive flow.
- **Police Dispatch** — ps-dispatch, cd_dispatch, lspd_dispatch supported. Per-drug alert chance.
- **Discord Webhooks** — Rich embed logging for sales, fails and police alerts. Stored in `server_config.lua`.
- **Day / Night Bonuses** — Configure separate sell bonuses per drug per time of day.
- **Server-side security** — All rolls and item checks happen server-side. pcall-wrapped, always returns a result to the client.
